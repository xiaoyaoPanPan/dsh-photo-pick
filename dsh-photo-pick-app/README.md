# dsh-photo-pick-app

English | [中文](README.zh.md)

Installable profile bundle for photo ranking: Host `ctx.photoPick` via `dsh-photo-pick-local`, plus a shippable **照片择优** agent preset (`dsh-photo-pick-setup-preset`).

See the feature README for install/uninstall commands: [`../README.md`](../README.md).

## Known Limitations

- Ranking is per-image quality scoring, not a pairwise tournament.
- Settings → Photo pick is always listed when this plugin is installed; the session-header workspace chip stays photo-pick-preset-only.
