# dsh-photo-pick-app

[English](README.md) | 中文

可安装的照片择优组合包：通过 `dsh-photo-pick-local` 挂上 Host `ctx.photoPick`，并附带 **照片择优** Agent Preset（`dsh-photo-pick-setup-preset`）。

安装/卸载命令见功能目录 README：[`../README.md`](../README.md)。

## Known Limitations

- 当前是逐张质量打分排序，不是两两对决。
- 「设置 → 照片择优」在插件安装后始终出现；会话顶栏工作区入口仍仅在「照片择优」Preset 下显示。
