# `dsh-photo-pick-ui`

English | [中文](README.zh.md)

Web settings section for photo-pick vision scoring (always listed when this plugin is installed). Lists Host LLM catalog models (same routes as Settings → Models), same pattern as media-library settings.

Session-header **照片择优** workspace (photo-pick preset only): dialog shell adapted from media Image & video scan — left folds for actions / **this-batch criteria** (quick chips + recent history) / model / scoring standard; right folder-or-flat thumbnail grid with lightbox; Confirm-to-chat fills paths plus `criteria` for the agent. On blank/hero sessions the header is hidden; use the composer tool-row **照片择优** chip instead (same preset gate).
