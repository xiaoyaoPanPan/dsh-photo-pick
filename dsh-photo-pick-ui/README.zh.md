# dsh-photo-pick-ui

[English](README.md) | 中文

照片择优的 Web 设置页（插件安装后始终出现在设置导航）：从 Host LLM 目录里选看图模型（与「设置 → 模型」同一路由），交互对齐素材库设置。

会话顶栏「照片择优」工作区（仅 `photo-pick` Preset）：布局对齐素材「图片与视频扫描」——左侧折叠为操作 / **本组要求**（内置芯片 + 最近历史） / 打分模型 / 打分标准；右侧目录或全部平铺缩略图与大图预览；勾选后「确定并填入对话」会带上本组 `criteria`。空白会话顶栏会隐藏，此时入口在输入框工具行左侧的「照片择优」芯片（同样 Preset 门控）。
